Política de privacitat — Eines JLP (Resum matinal)

Data: 23/10/2026

Català

«Eines JLP — Resum matinal» és una eina privada que només fa servir el seu propietari (JLP), amb els seus propis comptes de Google.

  1. Quines dades llegeix: calendaris (només lectura); correu (llegir-lo, etiquetar-lo i enviar el resum al mateix propietari); contactes (buscar-los i crear-ne de nous; mai modificar-los ni esborrar-los).
  2. Per a què: només per preparar el resum diari i respondre les consultes del propietari.
  3. On es guarden: a l'ordinador i al servidor propis del propietari. No hi ha cap servidor extern de l'eina.
  4. Amb qui es comparteixen: amb ningú. No es venen ni es fan servir per a publicitat.
  5. Processament amb IA: el resum diari es fa amb un model d'IA local, a l'ordinador del propietari. Quan el propietari ho demana, una part de les dades (per exemple, el contacte que busca) s'envia a l'assistent d'IA Claude (Anthropic) perquè li pugui respondre.
  6. Com retirar el permís: des de myaccount.google.com/permissions (Seguretat → Aplicacions de tercers).

L'ús de les dades obtingudes de les API de Google s'ajusta a la Política de dades d'usuari dels serveis d'API de Google, inclosos els requisits d'ús limitat.

English

"Eines JLP — Resum matinal" is a private tool used only by its owner (JLP), with the owner's own Google accounts.

  1. Data accessed: calendars (read-only); email (read, label, and send the summary to the owner); contacts (look up and create new ones; never edit or delete).
  2. Purpose: only to prepare the daily summary and answer the owner's requests.
  3. Storage: on the owner's own computer and server. The tool has no external server.
  4. Sharing: data is not shared with anyone, not sold and not used for advertising.
  5. AI processing: the daily summary is made with a local AI model on the owner's computer. When the owner asks, part of the data (for example, the contact being looked up) is sent to the AI assistant Claude (Anthropic) so it can answer.
  6. Revoking access: at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
